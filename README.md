# PremiumAlts

Модификация для клиента Minecraft (Fabric Loader), реализующая переключение и управление учетными записями непосредственно из главного меню игры.

---

## Архитектура и функциональные возможности

### 1. Управление учетными записями
- Отображение локального списка учетных записей с визуализацией скинов и никнеймов.
- Исключение служебных названий файлов из пользовательского интерфейса.
- Статусная индикация активной сессии.

### 2. Навигация и фильтрация
- Фильтрация списка учетных записей в реальном времени по введенному запросу.
- Применение выбранного профиля через кнопку интерфейса или двойным нажатием.

### 3. Хранение данных
- Автономное сохранение авторизованных профилей в директории `<gameDirectory>/alts/<username>.json`.
- Прямой вызов системного проводника для доступа к рабочей директории.

### 4. Поддерживаемые протоколы авторизации
- Импорт учетных данных из файлов конфигурации (форматы Netscape Cookie, JSON Cookie, Refresh Token).
- Импорт учетных данных напрямую из системного буфера обмена.
- Интерактивная OAuth 2.0 авторизация Microsoft с использованием локального веб-сервера.

### 5. Сетевая аутентификация
- Прямое взаимодействие с официальными сессионными сервисами Mojang (`https://sessionserver.mojang.com`).
- Изоляция сетевого стека от сторонних библиотек и сервисов инжекции (включая Ely.by и authlib-injector).

## Инструкция по сборке

Сборка всех версий проекта:
```cmd
build-all.bat
```

Сборка отдельной версии:
```cmd
cd <каталог_версии>
gradlew.bat build
```

Выходные файлы помещаются в каталог `dist/`.
