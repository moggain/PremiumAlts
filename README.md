# AltsMod — Внутриигровой менеджер аккаунтов для Minecraft Fabric

**AltsMod** добавляет кнопку **Alts** в главное меню Minecraft (рядом с кнопкой «Сетевая игра»), открывающую минималистичное меню смены аккаунтов с автоматическим сохранением профилей и обходом блокировок сессий.

---

## Особенности и возможности

1. **👤 Список аккаунтов (Скины и Ники):**
   - В левой панели отображается список сохраненных аккаунтов с их **головами (аватарами скинов)** и **никнеймами**.
   - Никаких лишних названий файлов — только чистый профиль игрока.
   - Текущий активный аккаунт помечается зелёной галочкой `✔`.

2. **🔍 Поиск и быстрый выбор:**
   - Встроенная строка поиска для быстрой фильтрации аккаунтов по нику.
   - Кнопка **«▶ ВОЙТИ»** для входа в выбранный аккаунт (или двойной клик по аккаунту в списке).

3. **💾 Автоматическое сохранение в корень игры (`alts/`):**
   - Все аккаунты сохраняются прямо в папку `<gameDirectory>/alts/<username>.json`.
   - Кнопка **«📂 Папка Alts»** открывает эту директорию в Проводнике Windows.

4. **⚡ Несколько способов входа:**
   - **📁 Выбрать файл аккаунта:** выбор файла с Cookie (Netscape/JSON) или refresh-токенами.
   - **📋 Вставить из буфера:** мгновенный вход из скопированных куков или токена.
   - **🌐 Войти через браузер:** интерактивная авторизация Microsoft OAuth через локальный веб-сервер.

5. **🛡️ Обход проверки сессий лаунчеров (Ely.by / TLauncher):**
   - Автоматически перенаправляет сессионную аутентификацию напрямую на официальные серверы Mojang PROD (`https://sessionserver.mojang.com`), предотвращая ошибки «Недействительная сессия» при входе на лицензионные серверы.

6. **✨ Дизайн:**
   - Анимированный золотой градиент надписи **Made by PremiumAlts**.

## Сборка проекта

Для сборки всех 5 версий одной командой запустите:
```cmd
build-all.bat
```
Либо перейдите в подпапку нужной версии и выполните:
```cmd
gradlew.bat build
```
Готовые JAR-файлы сохраняются в подпапку `dist/`.
